# LexiVoice

Voice-first vocabulary learning app built with React, TypeScript and Vite.

## Requirements
- Node.js 20 LTS or newer
- npm 10 or newer
- Chrome or Edge recommended for speech recognition

## Run locally
```bash
npm install
npm run build
npm run dev
```

## Production preview
```bash
npm run build
npm run preview
```

Speech recognition availability depends on the browser. Text input remains available as a fallback.
